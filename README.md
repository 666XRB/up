# 图片上传展示项目

这是一个支持跨设备共享的图片上传展示项目。

##### 功能特点

- **图片上传**：支持点击上传、拖拽上传（支持一次性选择多张图片）和拍照上传
- **图片池管理**：最多可上传5张图片，采用**队列（FIFO）结构**，超过时新上传的图片会顶替并自动移除最早上传的图片（先进先出原则）
- **图片预览**：点击图片（移动端短按）可放大预览
- **图片下载**：在预览模式中可以下载图片到本地
- **跨设备共享**：使用LeanCloud数据库实现，所有设备访问同一链接可以看到相同的图片池，实现真正的图片交换功能
- **实时同步**：任何设备上传或删除图片，其他设备会自动更新显示
- **图片删除**：桌面端右键删除，移动端长按删除
- **响应式设计**：适配不同屏幕尺寸，移动端体验优化

## 技术栈

- HTML5
- CSS3
- JavaScript (原生)
- HTML5 File API
- LeanCloud Storage (用于跨设备数据同步)

## 配置LeanCloud（必需）

要使用跨设备共享功能，您需要配置自己的LeanCloud项目：

1. 请参考项目根目录下的 `LEAN_CLOUD_GUIDE.md` 文件
2. 按照指南创建LeanCloud项目并获取配置信息
3. 在 `index.html` 文件中替换 `APP_KEY` 为您自己的配置信息（`APP_ID` 和 `SERVER_URL` 已预先配置）

**注意：** 如果不配置LeanCloud，应用将无法实现跨设备共享功能，但仍可在本地使用基础功能。

## 静态部署方法

这个项目是完全静态的，可以通过以下方式部署：

### 方法一：直接打开HTML文件

1. 在文件浏览器中找到 `index.html` 文件
2. 双击文件直接在浏览器中打开

### 方法二：使用静态文件服务器（推荐）

对于更好的性能和兼容性，推荐使用静态文件服务器：

#### 使用Python内置服务器

```bash
# Python 3.x
cd f:\Adaogu1\up
python -m http.server 8000
```

然后在浏览器中访问 `http://localhost:8000`

#### 使用Node.js的http-server

```bash
# 先安装http-server（如果尚未安装）
npm install -g http-server

# 启动服务器
cd f:\Adaogu1\up
http-server -p 8080
```

然后在浏览器中访问 `http://localhost:8080`

## 注意事项

- 所有数据仅存储在浏览器的localStorage中，不会上传到任何服务器
- 由于localStorage的限制，不建议上传过大的图片文件
- 清空浏览器缓存或使用隐私模式可能会导致存储的图片丢失
